## 📋 О проекте

**Monetrix** — это веб-приложение для агрегации финансовых данных из нескольких банков через OpenBanking API. Проект разработан для хакатона HackAPI 2025 и демонстрирует интеграцию с тремя банками: VBank, ABank и SBank.

### 🎯 Основная идея

Пользователь может зарегистрироваться в системе, подключить свои счета из разных банков и видеть все свои финансы в едином интерфейсе: балансы, транзакции, аналитику и рекомендации.

## 🚀 Технологический стек

### Frontend

- **React 19.1.1** — библиотека для создания пользовательских интерфейсов
- **TypeScript 5.9.3** — типизированный JavaScript
- **Vite 7.1.7** — быстрый сборщик и dev-сервер
- **React Router DOM 7.9.5** — маршрутизация в SPA

### Backend

- **FastAPI 0.104.1** — современный веб-фреймворк для Python
- **Uvicorn** — ASGI-сервер для запуска FastAPI
- **httpx** — асинхронный HTTP-клиент для запросов к банковским API
- **PyJWT** — работа с JWT токенами для аутентификации
- **Pydantic** — валидация данных и настройки

### Интеграции

- **OpenBanking API** — интеграция с тремя банками:
  - VBank (автоматическое одобрение согласий)
  - ABank (автоматическое одобрение согласий)
  - SBank (ручное одобрение согласий через веб-интерфейс)

## ✨ Реализованный функционал

### ✅ Аутентификация и авторизация

- Регистрация пользователей (физические и юридические лица)
- Вход в систему с JWT-токенами
- Автоматическое создание согласий для всех банков при регистрации
- Управление сессиями через localStorage

### ✅ Интеграция с банками

- Получение токенов доступа для каждого банка
- Создание согласий на доступ к финансовым данным
- Автоматическое управление жизненным циклом согласий
- Поддержка ручного одобрения согласий (SBank)
- Обработка pending-согласий с использованием `request_id`

### ✅ Дашборд

- **Сводка по счетам**: агрегированный баланс со всех банков
- **Список транзакций**: все транзакции из всех подключенных банков
- **Профиль пользователя**: информация о пользователе и статусы согласий

### ✅ Архитектура

- Модульная структура backend (разделение на routers, core, banks)
- Централизованная обработка ошибок
- Логирование для отладки интеграций
- Кэширование токенов и согласий

---

## ⚠️ Что не реализовано

### 🔴 Не реализовано

- **База данных**: используется in-memory хранилище (планировался PostgreSQL)
- **Создание счетов**: функционал создания новых счетов не реализован
- **Расширенная аналитика**: только базовые рекомендации
- **Уведомления**: нет системы уведомлений о транзакциях
- **Экспорт данных**: нет возможности экспортировать данные в CSV/PDF
- **Мобильная версия**: только веб-интерфейс
- **Тестирование**: отсутствуют unit и integration тесты

### 🟡 Частично реализовано

- **Обработка ошибок**: базовая обработка, но не все edge cases покрыты
- **Валидация данных**: частичная валидация на backend
- **UI/UX**: базовый интерфейс, требует улучшения дизайна

## 🛠️ Установка и запуск

### Предварительные требования

- **Node.js** 18+ и **npm**
- **Python** 3.10+
- **Git**

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd monetrix
```

### 2. Backend (FastAPI)

```bash
# Перейти в папку backend
cd backendV2

# Создать виртуальное окружение (опционально, но рекомендуется)
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Запустить сервер
uvicorn backendV2.app:app --reload --host 0.0.0.0 --port 8080
```

Backend будет доступен по адресу: `http://localhost:8080`

### 3. Frontend (React)

```bash
# Вернуться в корень проекта
cd ..

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Frontend будет доступен по адресу: `http://localhost:5173`

### 4. Использование

1. Откройте `http://localhost:5173` в браузере
2. Зарегистрируйтесь, выбрав `bankClientId` (например, `team217-1` до `team217-10`)
3. После регистрации автоматически создадутся согласия для всех банков
4. Для SBank нужно подтвердить согласие вручную на сайте банка
5. После подтверждения данные появятся на дашборде

## 🔐 Конфигурация

### JWT настройки

Настройки JWT находятся в `backendV2/core/auth.py`:

- Секретный ключ: `your-secret-key-change-in-production`
- Время жизни токена: 30 дней

⚠️ **Важно**: В production необходимо использовать безопасный секретный ключ!

## 📡 API Endpoints

### Аутентификация

- `POST /api/auth/register` — Регистрация пользователя
- `POST /api/auth/login` — Вход в систему

### Согласия

- `POST /api/consents` — Создать новое согласие
- `GET /api/consents/{consent_id}/status` — Статус согласия
- `DELETE /api/consents/{consent_id}` — Отозвать согласие

### Дашборд

- `GET /api/profile` — Профиль пользователя и согласия
- `GET /api/dashboard/summary` — Сводка по счетам
- `GET /api/dashboard/transactions` — Список транзакций
- `GET /api/recommendations` — Рекомендации

Все endpoints (кроме `/api/auth/*`) требуют JWT токен в заголовке `Authorization: Bearer <token>`
